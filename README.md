# 🍔 Burger Shop - Premium Landing Page

A stunning, dark-themed landing page for a burger restaurant featuring bold typography, dramatic visual effects, and modern design aesthetics.

![Burger Shop Preview](https://images.unsplash.com/photo-1568901346375-23c9450c58cd?w=1200&h=600&fit=crop&q=80)

## ✨ Features

### Design
- **Dark Premium Aesthetic** - Deep black background with high-contrast white text
- **Bold Typography** - Black Ops One display font for dramatic headlines
- **Orange Accent Colors** - Vibrant orange (#FF6B35) for CTAs and highlights
- **Responsive Design** - Fully responsive across desktop, tablet, and mobile devices

### Interactive Elements
- **Burger Carousel** - Interactive thumbnail gallery with smooth navigation
- **Floating Animations** - Sesame seeds and sauce dripping effects
- **Dynamic Particles** - Subtle floating particle effects
- **Hover Effects** - Card lifts, image zooms, and smooth transitions
- **Shopping Cart** - Live cart counter with add-to-cart functionality
- **Contact Form** - Functional contact form with validation

### Sections
1. **Hero Section** - Full-screen hero with split layout and dramatic burger showcase
2. **Burger Carousel** - Thumbnail gallery to preview different burgers
3. **Menu Section** - Product cards with images, descriptions, prices, and badges
4. **Contact Section** - Contact information and inquiry form
5. **Footer** - Brand information and quick links

## 🚀 Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript (Vanilla)** - No frameworks, pure JavaScript for interactivity
- **Google Fonts** - Black Ops One & Outfit
- **Unsplash** - High-quality burger photography

## 🛠️ Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/burgerShop.git
   cd burgerShop
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your browser
   open index.html

   # Or use a local server (recommended)
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

3. **No build process required!** This is a pure HTML/CSS/JS project.

## 📱 Responsive Breakpoints

- **Desktop**: 1024px and above
- **Tablet**: 768px - 1024px
- **Mobile**: Below 768px
- **Small Mobile**: Below 480px
